## Points d'attention
1. **Backfill historique** : `20261024_member_reactivation.sql` contient `update profiles set last_member_visit_at = now() where last_member_visit_at is null and status = 'approved'`. Ne jamais la rejouer ; vérifier dans Supabase si elle a déjà été exécutée (les dates d'activité des membres existants en dépendent).
2. **Livraison e-mail / push** : ni SMTP ni Web Push ne garantissent « exactement une fois ». Le cron peut, dans un cas rare (e-mail accepté puis arrêt du processus avant l'écriture `sent`), renvoyer un palier après la reprise d'une prise en charge périmée (> 1 h). Le push peut être réexpédié à certains appareils après une livraison partielle suivie d'une reprise.
3. **Test existant en échec, hors périmètre** : `src/lib/matching/__tests__/matching-engine.test.ts` (« Samuel and Grace should have high semantic similarity », 38 attendu > 50) échoue indépendamment de ce travail ; le module de matching n'a pas été modifié.
4. **Erreurs `tsc` préexistantes** : `src/lib/matching/__tests__/matching-engine.test.ts` (types `null`, `describe` non typé) ; non liées à ce travail.
