# **App Name**: Eden Rencontre

## Core Features:

- User Faith Profile Creation: Guided multi-step form to capture detailed faith-based information, including denomination, practice frequency, and vision for family, forming a 'Profil de Foi'.
- Member Dashboard & Profile Management: Personalized dashboard for users to manage their profile details, view notifications, and access their faith profile.
- Advanced Search & Filtering: Robust search functionality allowing users to filter potential matches by criteria such as country, education level, religious denomination, and desire for marriage.
- Secure Internal Messaging: A protected internal chat system that prevents sharing of external links or phone numbers during initial interactions to safeguard users from fraud.
- Coup de Cœur (Interest) System: Allows users to discreetly express interest in another profile without immediately initiating a message.
- AI-Powered Identity Verification: Utilize an AI tool for real-time photo verification against provided identity documents to offer a 'Profil Certifié' badge, enhancing user trust and moderation.
- Premium Subscription Management: A clear pricing structure for premium memberships, enabling access to advanced features and managing subscription states.

## Style Guidelines:

- Primary color: Deep Night Blue (#1A237E) to symbolize fidelity and depth, forming the core of the refined aesthetic.
- Accent color: Matte Gold (#C5A021) to signify preciousness, sacredness, and a premium feel.
- Background color: A subtly dark, desaturated blue-grey (#1D2126) derived from the primary hue, ensuring a sophisticated and serene backdrop that highlights content.
- Complementary text and UI element color: Pure White (#FFFFFF) for clarity and transparency across the dark theme.
- Headline font: 'Playfair' (Serif) for an elegant, high-end, and literary feel. Note: currently only Google Fonts are supported.
- Body font: 'PT Sans' (Sans-Serif) for a modern, legible, and professional reading experience, paired with the headline font. Note: currently only Google Fonts are supported.
- Responsive and fluid design ensures an optimal viewing and interaction experience across all devices, from mobile to desktop, adhering to a sophisticated visual language.
- Subtle, light animations on hover states and transitions to provide a polished and interactive user interface without distraction.
